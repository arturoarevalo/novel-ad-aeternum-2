# estado/

Instantáneas del mundo **después** de cada capítulo: `despues-cap-NN.md`.

Las genera el **archivista** al cerrar un capítulo. Cada una resume el estado al final de ese capítulo (dónde está cada personaje, qué sabe, qué ha cambiado, qué queda pendiente) para que el siguiente capítulo arranque con contexto **compacto** sin releer todo lo anterior. Esto mantiene el coste en tokens lineal en vez de cuadrático.

No se escriben a mano salvo corrección puntual.
