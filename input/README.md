# input/

Deja aquí el material de partida ANTES de lanzar `/arquitecto`. Puede ser cualquier mezcla de:

- **idea**: una sinopsis, un par de párrafos, notas sueltas.
- **manuscrito**: capítulos o la novela entera ya escrita (para reescribir/continuar).
- **revisiones**: informes de lectura, correcciones, comentarios editoriales.
- **referencias**: documentación, comparables, ambientación.

Formato libre en markdown o texto. `/arquitecto` lo lee todo y construye la biblia. Si marcas pasajes como **intocables** (p. ej. con `<<INTOCABLE>> … <<FIN>>`), se respetarán literalmente.
